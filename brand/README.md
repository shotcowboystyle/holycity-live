# Holy City Live — Brand Assets v1.0 (October 2026)

**Identity:** Harbor Gauge (steeple as gauge needle over harbor water)

All logo artwork is outlined (no live fonts, no strokes). Scale freely; never redraw.

## 01-logo

`01-logo/svg`, `01-logo/png` — file pattern: `holy-city-live_<lockup>_<colorway>`

### Lockups

| Lockup | Use | Minimum size |
| --- | --- | --- |
| `horizontal` | Primary. Symbol + wordmark + "CHARLESTON, S.C." dateline. | 320 px / 3.5 in wide |
| `horizontal-compact` | No dateline. Nav bars, footers, small placements. | 140 px / 1.25 in wide |
| `stacked` | Square or narrow spaces. | 200 px / 2 in wide |
| `wordmark` | Only when the symbol already appears nearby. | 120 px / 1 in wide |
| `symbol` | Full symbol. | 48 px / 0.5 in |
| `symbol-small` | Simplified cut for 16–47 px. Do not use above 64 px. | — |

### Colorways

| Colorway | Use |
| --- | --- |
| `color` | Ink + Harbor. For Paper or white grounds. |
| `reverse` | Paper + Harbor Light. For Ink grounds. |
| `ink` | One color, Ink. Single-color print, stamps, engraving. |
| `white` | One color, white. Harbor grounds and dark, calm photo areas. |

PNGs are transparent, high resolution.

## Quick rules

- **Clear space:** X = 1/4 of the symbol's diameter, on all sides of any lockup.
- **Colors:** Ink `#141A22` · Harbor `#1D4E89` · Harbor Light `#8FB6E3` · Paper `#F6F4EE`
- Harbor Light is for Ink grounds only (1.9:1 on Paper — fails).
- Never stretch, rotate, recolor, add effects, rearrange, or retype the logo.
- **Name:** "Holy City Live" — three words, title case. Not "HCL", not "HolyCityLive" (handles and URLs excepted).
